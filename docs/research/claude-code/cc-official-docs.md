== 1. TOOLS REFERENCE (https://code.claude.com/docs/en/tools) ==
~50 built-in tools; the doc's summary table shows permission tier per tool (read-only vs edit vs execute). Core set with behavior contracts:
• Read: path+offset/limit; token-capped pagination with `PARTIAL view` notice; images/PDF(10pp→`pages` 1-5 style, ≤20pp/call)/ipynb special-cased; read-only tier.
• Grep: ripgrep syntax, output modes files_with_matches|content|count, glob/type scoping, multiline, respects .gitignore (Glob does NOT by default — CLAUDE_CODE_GLOB_NO_IGNORE). Read-only.
• Glob: mtime-sorted, 100-file cap w/ truncation flag. Read-only.
• Edit: exact string replace old_string→new_string; 3 gates: read-before-edit (relaxed for newer models when read wouldn't prompt), exact match, uniqueness (+replace_all); stale-read re-reads. Edit tier. `Edit(/src/**)` allow implies read grant of same path; `Read` deny blocks Edit/Write on the path too.
• Write: full overwrite; read-before-overwrite rules per model. Edit tier.
• NotebookEdit: cell_id-targeted replace|insert|delete, permission-ruled as Edit(path). 
• Bash: per-command separate process; cd persists within workdirs (CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR=1 disables); env vars don't persist (CLAUDE_ENV_FILE / SessionStart hook to persist); sources ~/.zshrc aliases at startup; timeout default 2min (BASH_DEFAULT_TIMEOUT_MS) ceiling 10min (BASH_MAX_TIMEOUT_MS); output streamed to file, killed at 5GB, inline 30k chars valid/10k failure (BASH_MAX_OUTPUT_LENGTH→150k, bashOutputMaxChars≤128k); exit 1 benign for grep/rg/find/diff/test/git diff; auto-backgrounding on timeout EXCEPT sleep*/git/unparseable compounds; run_in_background:true param; /tasks lists+stops. Execute tier.
• PowerShell: opt-in native pwsh tool (CLAUDE_CODE_USE_POWERSHELL_TOOL), same permission/hook surface, matcher `Bash|PowerShell`.
• Monitor: background watcher feeding each output line as an event mid-conversation; also WebSocket source (ws:// URL, 1MiB msg cap); same permission rules as Bash; private/metadata addresses denied.
• WebFetch: fetch→markdown→small-model extraction with a prompt (lossy by design); 15min cache (CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS); cross-host redirect NOT followed (returns notice); per-domain prompts with `WebFetch(domain:…)` rules; preapproved doc-domain set.
• WebSearch: Anthropic backend, ≤8 backend queries/call, allowed_domains/blocked_domains, 200 calls/session cap (CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION), bare tool name rules only.
• Agent (ex-Task, renamed v2.1.63): spawn subagent, returns single final result; `Agent(agent_type)` rule syntax; per-invocation model param.
• AskUserQuestion: {questions:[{question,header,options:[{label}…],multiSelect}]} schema; questions stay open until answered, optional askUserQuestionTimeout (60s/5m/10m) auto-continues; never auto-approved in any mode.
• Task tools (TaskCreate/Get/List/Update, TodoWrite): disabled by default on newest models unless CLAUDE_CODE_ENABLE_TODO_TOOLS=1 or explicitly allowed.
• Others: EnterPlanMode/ExitPlanMode (plan presentation→approve options), EnterWorktree/ExitWorktree, CronCreate/Delete/List (session-scoped scheduled tasks), SendMessage/ListAgents (agent teams + cross-session), Workflow (scripted multi-subagent orchestration), ToolSearch (deferred MCP tool loading), WaitForMcpServers, LSP (via code-intelligence plugins; auto reports type errors after edits), Skill, Artifact, PushNotification, ReportFindings, ScheduleWakeup (/loop), EndConversation (abuse-only safeguard, cannot be denied/removed, hooks skip it), RemoteTrigger, TaskOutput (deprecated→Read output file), TaskStop.
• xdev verdict — ADOPT: exact-string Edit semantics w/ uniqueness+read-before-edit, benign-exit-1 command list, output-to-file overflow pattern, Grep/Glob gitignore asymmetry, WebFetch redirect-refusal, ToolSearch-style deferred MCP tool loading (M0-M5, tools milestones). VERIFY: Bash auto-backgrounding-on-timeout + no-auto-background list (xdev should implement or consciously skip). REJECT: plan-surface tools (Artifact/RemoteTrigger/PushNotification/ShareOnboardingGuide) — cloud/claude.ai products.

== 2. HOOKS (https://code.claude.com/docs/en/hooks) ==
~35 events, 3 cadences: per-session (SessionStart, SessionEnd, Setup), per-turn (UserPromptSubmit, UserPromptExpansion, Stop, StopFailure), per-tool (PreToolUse, PostToolUse, PostToolUseFailure, PostToolBatch, PermissionRequest, PermissionDenied). Plus: Notification, MessageDisplay (streaming display transform), SubagentStart/Stop, TaskCreated/Completed, TeammateIdle, InstructionsLoaded (CLAUDE.md load audit), ConfigChange, CwdChanged, DirectoryAdded, FileChanged (watch paths), WorktreeCreate/Remove, PreCompact/PostCompact, PreModelSwitch/PostModelSwitch, Elicitation/ElicitationResult.
• Config: settings JSON `hooks:{Event:[{matcher, hooks:[{type,command/if/timeout/async…}]}]}`. Locations: user/project/local/managed/plugin hooks.json/skill frontmatter/subagent frontmatter; entries MERGE across layers; allowManagedHooksOnly for enterprises; disableAllHooks can't kill managed hooks.
• Matcher: exact string OR `|`/`,`-separated list OR unanchored JS regex (any other char); per-event filter field (tool name for tool events, source for SessionStart, agent type for SubagentStart/Stop…). `if` field on handlers = permission-rule syntax (`Bash(rm *)`) to pre-filter without spawning. MCP tools: `mcp__server__.*` (bare `mcp__server` is exact-string and matches nothing — footgun).
• Handler types (5): command (stdin JSON, exit codes + stdout), http (POST JSON, response body = same output format), mcp_tool (call connected server's tool), prompt (single-turn LLM decision), agent (experimental: subagent w/ tools verifies). `async: true` for background.
• Output contract: exit 0 = proceed (stdout parsed as JSON if `{…}`-wrapped, else plain text context for UserPromptSubmit/UserPromptExpansion/SessionStart/PostModelSwitch); exit 2 = block (stderr→reason) on blocking events; other exits = non-blocking error notice. JSON: universal fields (continue, stopReason, suppressOutput, systemMessage, decision/reason); PreToolUse uses hookSpecificOutput.permissionDecision: allow|deny|ask|defer + permissionDecisionReason + updatedInput (FULL input replacement, re-evaluated against rules) + additionalContext; precedence deny>defer>ask>allow. allow+updatedInput can programmatically answer AskUserQuestion/ExitPlanMode in -p runs. PermissionRequest: decision{behavior:allow|deny, updatedInput, updatedPermissions[addRules/replaceRules/removeRules/setMode/addDirectories/removeDirectories w/ destination session|localSettings|projectSettings|userSettings], message, interrupt}. UserPromptSubmit: decision:block + reason + additionalContext + sessionTitle. SessionStart: additionalContext, initialUserMessage (-p), sessionTitle, watchPaths, reloadSkills, CLAUDE_ENV_FILE persistence. Stop/PostToolUse use top-level decision: block + reason.
• xdev verdict — ADOPT the whole model (xdev hooks milestone): event set, matcher+`if` two-stage filtering (big perf win), exit-2 convention, hookSpecificOutput w/ updatedInput mutation, permission-destination writes. DO DIFFERENTLY: skip enterprise/managed layer initially; consider prompt/agent hook types as post-M14.

== 3. SUBAGENTS (https://code.claude.com/docs/en/sub-agents) ==
MD files, YAML frontmatter + body=system prompt. Locations/priority: managed > --agents CLI JSON > .claude/agents/ (walks up to repo root, closest-to-cwd wins on name clash) > ~/.claude/agents/ > plugin agents/ (scoped id `plugin:name`). Frontmatter fields (name+description required): tools (allowlist; inherits all if omitted), disallowedTools (applied first; supports `mcp__server`/`mcp__*` patterns), model (alias|full-id|inherit; resolution: per-invocation param > frontmatter > CLAUDE_CODE_SUBAGENT_MODEL > parent; CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 pins all), permissionMode (default|acceptEdits|auto|dontAsk|bypassPermissions|plan; parent bypass/acceptEdits wins; parent auto ignores child mode), maxTurns (partial-output + resumable), skills (preload full content), mcpServers (inline defs or name refs; scoped to agent lifetime; trust-gated in project dirs), hooks, memory (user|project|local → agent-memory dir + 200-line MEMORY.md head injected + auto Read/Write/Edit), effort, isolation: worktree (auto-cleanup if no changes; bash worktree-escape checks), background:true, color, initialPrompt, experimental.cacheTtl. Built-ins: Explore (read-only, model=parent capped at Opus, skips CLAUDE.md+git status, thoroughness quick/medium/very thorough), Plan (plan-mode researcher), general-purpose, claude (catch-all), statusline-setup, claude-code-guide. Tool filters: subagents never get AskUserQuestion, EnterPlanMode, ScheduleWakeup, EndConversation, Workflow, TaskOutput…; background subagents get a narrowed built-in set. Background by default; fork mode runs them backgrounded w/ full parent inheritance. Depth-limited nesting (Agent at depth limit errors). 15k-token combined-description warning. @-mention invocation; Agent(subagent-name) deny rules; hot-reload of agent files within seconds. Subagent edits usually NOT captured by checkpoints.
• xdev verdict — ADOPT: frontmatter schema (name/description/tools/disallowedTools/model/permissionMode/maxTurns/skills/memory), built-in Explore/Plan pattern w/ CLAUDE.md skipping, background-vs-foreground default (xdev's task agents = foreground; consider background), resumable partial results. VERIFY: description-token budget warning. REJECT: nothing core.
