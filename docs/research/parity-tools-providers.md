Go: fs + archive/sqlite stdlib + reader-mode fetcher; summary = optional (NICE).
- **edit** (CORE): default contract is **hashline** — `[PATH#TAG]` sections with 4-hex content-derived snapshot tag from last read/grep/edit; ops `PUT N.=M:` / `PUT N*` (tree-sitter block) / `PUT <N`/`>N`/`>$` / `CUT`+named registers / `REM` / `MV`; final-content `+` rows (not diff); stale-tag snapshot recovery; edits outside seen lines rejected; apply_patch/patch/replace alternate modes per model. Go: implement tag+snapshot store; block anchors need tree-sitter → ship line ops first, block ops NICE.
- **write** (CORE): also writes archive entries (whole-container atomic rewrite), SQLite rows (JSON5, empty=delete), `conflict://`, internal URLs, and `xd://<tool>` JSON device dispatch; strips pasted hashline prefixes; blocks likely read/write mis-dispatch and generated-file overwrite.
- **grep / glob** (CORE): semicolon multi-path, gitignore+hidden defaults, native regex→PCRE2→literal fallback (Go: regexp2/stdlib+RE2, literal fallback), 20-file page + `skip`, per-file caps 20/200, 30s timeout; glob: mtime-sorted, limit 200, 5s timeout, prefix-folded tree output, multi-root concurrent.
- **bash** (CORE): `timeout` (default 300s, clamp 1..3600), `env`/`cwd`, optional PTY (exclusive), `async:true` background jobs; **bash.patterns** ordered glob rules allow/prompt/deny checked per segment; **bashInterceptor** regex rules route cat/grep/sed/echo→dedicated tools (only when target tool present — best-effort, not security).

## B. Agent coordination

- **todo** (CORE): single-op mutations (`init/start/done/drop/block/unblock/rm/append/view`) over phases; statuses pending/in_progress/completed/abandoned/blocked+reason; single-active-task normalization; errors discard the whole op; markdown round-trip for `/todo`; failures inject hidden next-turn reminder; subagents stripped of it unless prewalk-armed. - **ask** (CORE): interactive option-picker/multi-question dialog (`id/question/options{label,description,preview}/multi/recommended`); timeouts auto-select recommended; plan mode disables timeout; exclusive concurrency; **headless throws** — Go TUI: bubbles list dialog; skip in RPC mode.
